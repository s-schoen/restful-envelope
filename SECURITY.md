# Security Policy

## Supported Versions

Security reports should target the current `master` branch.

## Reporting a Vulnerability

Please report suspected security vulnerabilities through GitHub private vulnerability reporting:

https://github.com/s-schoen/restful-envelope/security/advisories/new

Do not open public GitHub issues for suspected security vulnerabilities.

## Coordinated Disclosure

Please keep vulnerability details private until the issue has been investigated and, when needed, a fix or advisory is
available.

## What to Include

Helpful reports include:

- A description of the vulnerability.
- Steps to reproduce or a proof of concept.
- The affected code path, configuration, or deployment scenario.
- The expected impact.
- Known mitigations or workarounds, if any.

## Non-Security Issues

Please use regular GitHub issues for:

- General bugs without a security impact.
- Dependency update requests without a known exploitable vulnerability.
- Scanner findings without a plausible impact explanation.
- Questions, support requests, or feature requests.
